## Implementation and experiments

- Shared packet versions are discriminated in TS/Zod/generated JSON Schema: v1=200 ms, v2=250 ms; mixed version/timing is rejected. The Hamming codebook stays unchanged. V2 goldens are generated separately; legacy golden packets stay intact. Existing boundary fixtures were regenerated for schema field ordering only.
- Backend and mock new runs select v2; the client explicitly selects the packet from its frozen plan. Admin countdown, presentation stage and camera-upload gating derive 11,750 ms from versioned timing, with an exact before/at-boundary upload test. Backend runTag remains monotonic ordering metadata and is never flashed in v2; session/epoch/hash/revision controls stay intact.
- V2 jointly evaluates all 2,048 repeated codewords on observed bit coordinates. A unique nearest candidate is accepted inside its actual punctured-code correction radius (2*errors < minimum observed separation), supporting complementary erasures. Three errors in one pass can miscorrect that pass alone; the stronger joint proof may recover the true ID. Two genuinely conflicting valid words remain ambiguous. Legacy single-pass acceptance remains a fallback with evidence warnings. Membership never narrows codebook fitting.
- Header phase is fitted from known colors/preamble, never a desired ID. Missing/washed pilots use preamble color evidence. At least five of seven preamble bits must be observed, including two of each color, with no contradicting bits; distinct timing hypotheses reject. A packet may begin before clip PTS zero when pilots are cropped. V2 fits each phone independently instead of rejecting a correct packet for a >75 ms inter-phone phase difference. Legacy v1 timing/header/tag acceptance remains unchanged.
- Saturated red uses compact cores only when the manifest declares red. A first universal-red-mask experiment regressed the amber five-phone clip to 4/5; the failed result is preserved as `runtime/otc-recall-investigation/v2-legacy-five.result.json`. Restricting the mask to red palettes restores 5/5 and preserves the old amber segmentation. A synthetic warm-skin/centroid regression covers the demonstrated mechanism.
- Development failures corrected: first phase-ambiguity bound incorrectly treated a contiguous valid timing plateau as multiple phases; first adversarial test incorrectly assumed codewords 0/1 differ by four bits (they differ by six; the distance-four test uses 0/3). Typecheck caught a test's widened numeric bit array and a legacy test factory needing a discriminated-union type. Initial fixture check caught only key ordering after the schema migration; generated fixtures now match.
